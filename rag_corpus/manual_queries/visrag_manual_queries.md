# Ручные запросы для проверки VisRAG

Использовать после экспорта runtime-корпуса:

    python scripts/rag_corpus/run_export_runtime.py --profile validated

## 1. Сравнение категорий с высокой кардинальностью

Запрос:

    Нужно сравнить продажи по 80 категориям товаров. График должен показать лидеров и не быть перегруженным.

Ожидаемые блоки RAG:

- `compare_amounts`
- `labels_legends_units`
- `readability`
- правила про сортировку, top-N, длинные подписи, перегрузку категорий

## 2. Плотный scatter-график

Запрос:

    Есть две числовые переменные и 50 000 строк. Нужно показать связь, но обычный scatterplot нечитаем из-за наложения точек.

Ожидаемые блоки RAG:

- `overplotting`
- `color_mark_discriminability`
- `readability`
- правила про transparency, density/binning, сохранение редких точек

## 3. Распределение с выбросами

Запрос:

    Нужно показать распределение цены, но в данных есть сильные выбросы и длинный правый хвост.

Ожидаемые блоки RAG:

- `distributions`
- `axes_baseline`
- `readability`
- правила про bin width, выбросы, сглаживание, форму распределения

## 4. Цвет для отклонения от нормы

Запрос:

    Нужно цветом показать, какие значения выше и ниже нормы. Норма равна нулю.

Ожидаемые блоки RAG:

- `color_scale_type`
- `color_accessibility`
- `color_semantics`
- правила про diverging scale, осмысленный центр, доступность цвета

## 5. График должен быть понятен без пояснений

Запрос:

    График непонятен без исходного текста задачи: неясно, что на осях, какие единицы измерения и что означает цвет.

Ожидаемые блоки RAG:

- `labels_legends_units`
- `readability`
- `accessibility`
- правила про title, axis labels, legend title, units, текстовое описание
